# VocabVerse — GRE Vocabulary Studio

A small FastAPI + vanilla-JS app that teaches one GRE word at a time: meaning,
Bengali translation, nuance, etymology, examples, memory trick and a practice
question — generated by an LLM.

## Setup

```bash
python -m venv .venv
.venv/Scripts/activate          # Windows
pip install -r backend/requirements.txt

cp .env.example .env            # then add at least one API key
```

Any one of `MISTRAL_API_KEY`, `GEMINI_API_KEY` or `OPENROUTER_API_KEY` is
enough. `LLM_PROVIDER` picks which one is tried first; the app automatically
falls back to the others if that provider fails.

## Run

```bash
uvicorn backend.main:app --reload --port 8000
```

Then open <http://127.0.0.1:8000/> — the backend serves the frontend, so there
is nothing else to start.

## API

| Method | Route         | Purpose                                      |
| ------ | ------------- | -------------------------------------------- |
| `GET`  | `/api/health` | Status and which providers are configured    |
| `POST` | `/api/vocab`  | `{"word": "ephemeral"}` → full vocabulary entry |

Successful lookups are cached in memory (128 most recent words), so repeat
lookups are instant and cost nothing.

## Notes

- `/?word=ephemeral` deep-links straight to a word.
- Progress (words explored, quiz accuracy, day streak, saved words) is stored
  in the browser's `localStorage` — there is no account system.
- Model responses are normalised server-side, so a malformed or partial reply
  from the LLM still renders correctly.
